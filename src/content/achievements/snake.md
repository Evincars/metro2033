**Snake **is an [achievement/trophy](https://metrovideogame.fandom.com/wiki/Achievements_and_Trophies) in [Metro 2033 Redux](https://metrovideogame.fandom.com/wiki/Metro_2033_Redux).

## Overview

This achievement is awarded for stealthily killing 15 enemies. This can be done on any enemy in any way (for example using the [knife](https://metrovideogame.fandom.com/wiki/Trench_Knife), [throwing knives](https://metrovideogame.fandom.com/wiki/Throwing_Knives), a silenced [weapon](https://metrovideogame.fandom.com/wiki/Weapons) or a pneumatic weapon), as long as you are undetected whilst doing so. Obtaining stealth kills on [mutants](https://metrovideogame.fandom.com/wiki/mutants) is much harder than on humans, as they hardly ever stay in one place and can usually detect the player more easily, so killing human enemies (such as [Bandits](https://metrovideogame.fandom.com/wiki/Bandits) or [Nazis](https://metrovideogame.fandom.com/wiki/Nazis)) is much easier when going for this achievement.
