**Blogger** is an [achievement/trophy](https://metrovideogame.fandom.com/wiki/Achievements_and_Trophies) in [Metro 2033 Redux](https://metrovideogame.fandom.com/wiki/Metro_2033_Redux).

## Overview

This achievement is awarded for finding all 51 of Artyom's hidden diary pages. There is a detailed guide found [here](https://metrovideogame.fandom.com/wiki/Artyom's_Journal_(Metro_2033_Redux)). This must be completed in one playthrough, but you can use chapter select to find the ones you have missed.
